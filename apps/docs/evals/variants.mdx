Each task defines one grid column:

```ts
{ harness: "codex", model: "gpt-5.6-sol" }
```

| Field | Purpose |
| --- | --- |
| `harness` | Runs the agent and its tools |
| `model` | Selects the harness model |
| `sandbox` | Where the trial runs. Optional, defaults to `e2b` |

## Agents

| Agent | `harness` | Credential | Reports |
| --- | --- | --- | --- |
| Codex | `codex` | API key or ChatGPT | Commands, files, tokens |
| Claude Code | `claude` | API key | Commands, files, tokens |
| OpenCode | `opencode` | Auth file | Commands, files, tokens |
| Pi | `pi` | Auth file | Commands, files, tokens |
| Gemini CLI | `gemini` | API key | Commands, files, tokens |
| Qwen Code | `qwen` | API key | Commands, files, tokens |
| Cursor Agent | `cursor` | API key | Commands, files |
| FX | `fx` | AI Gateway key or ChatGPT auth file | Tool names, answer |

Each agent needs a [connection](/connections). Agents with fewer reports still use the same verifier but leave less trajectory and cost data.

For Claude Code, follow the [setup guide](/guides/claude-code) to verify one trial before comparing models.

## Models

Model ids vary by agent. Use the catalogue when choosing one:

```ts
const { models } = await anpord.evals.models({ harness: "codex" });
```

Model discovery is not required before a run. Available ids depend on the harness.

## Sandboxes

`sandbox` is optional. A task that omits it runs on `e2b`:

```ts
tasks: [{ harness: "codex", model: "gpt-5.6-sol" }]
```

The rest are `daytona`, `upstash`, `modal`, `cloudflare`, and `vercel`. Every trial gets an isolated workspace.

The sandbox is part of the cell key, so adding or removing it starts a new history. Name one explicitly to keep an existing baseline.

## Compare variants

Change one field at a time:

```ts
tasks: [
  { harness: "codex", model: "gpt-5.6-sol" },
  { harness: "codex", model: "gpt-5.6-terra" },
]
```

Changing the harness, model, or sandbox creates a new cell history. A new harness version remains in the same history. Use a [profile](/evals/profiles) to compare an agent's stock and configured forms.
