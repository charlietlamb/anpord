## Prerequisites

Add a [model connection](/connections), then create an API key with `evals:write` and `evals:read` under **Settings > API keys**.

```bash
export ANPORD_API_KEY="anp_..."
```

## Install

<CodeGroup>

```bash npm
npm install anpord
```

```bash bun
bun add anpord
```

</CodeGroup>

## Define the eval

Create `smoke.eval.ts`:

```ts
import { suite, empty } from "anpord";

export default suite({
  name: "smoke",
  source: empty,
  prompt: "{{task}}",
  cases: [
    {
      name: "writes hello",
      variables: { task: "Create hello.txt containing exactly hello" },
      verify: 'test "$(cat hello.txt)" = hello',
    },
  ],
  tasks: [{ harness: "codex", model: "gpt-5.6-sol" }],
  trials: 3,
});
```

## Run it

```bash
npx anpord eval ./smoke.eval.ts
```

Anpord compiles the TypeScript locally, then runs each trial in an isolated hosted sandbox. Each cell's first scored result becomes its baseline.
