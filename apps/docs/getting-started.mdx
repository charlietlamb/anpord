## Prerequisites

Model usage is charged to your own account, so add a [connection](/connections) for the harness first — this example uses Codex. Sandboxes run on Anpord's accounts unless you add one of your own.

Then create a key under **Settings > API keys**:

```bash
export ANPORD_API_KEY="anp_..."
```

The key needs `evals:write` and `evals:read`. The example below pins a model id; find the ones your connection can reach with `anpord.evals.models({ harness: "codex" })`.

## Install

## Run an eval

Create `eval.ts`:

```ts
import { Anpord } from "anpord";

const anpord = new Anpord();

const run = await anpord.evals.startAndWait({
  cases: [
    {
      name: "writes the requested file",
      variables: { task: "Create hello.txt containing exactly hello" },
      verify: "test \"$(cat hello.txt)\" = hello",
    },
  ],
  prompt: "Work in the current repository. {{task}}",
  tasks: [{ harness: "codex", model: "gpt-5.6-sol", provider: "daytona" }],
  trials: 3,
});

if (run.status === "failed") {
  throw new Error(run.failure ?? "Eval run failed");
}

const result = run.cells[0]?.distribution;
if (!result) throw new Error("Run produced no result");

console.log({ passRate: result.passRate, scored: result.scored });
await anpord.dispose();
```

Run it:

```bash
bun eval.ts
```

Each trial runs in its own sandbox. The first scored result becomes the baseline for this case, harness, harness version, model, and sandbox provider.
