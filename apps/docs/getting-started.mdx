## Prerequisites

Add a [model connection](/connections), then create an API key with `evals:write` and `evals:read` under **Settings > API keys**.

```bash
export ANPORD_API_KEY="anp_..."
```

## Install

<CodeGroup>

```bash npm
npm install anpord
```

```bash bun
bun add anpord
```

</CodeGroup>

## Define the eval

Create `smoke.eval.ts`:

```ts
import { suite } from "anpord";

export default suite({
  name: "smoke",
  prompt: "{{task}}",
  cases: [
    {
      id: "writes-hello",
      name: "writes hello",
      variables: { task: "Create hello.txt containing exactly hello" },
      verify: 'test "$(cat hello.txt)" = hello',
    },
  ],
  variants: [{ harness: "codex", model: "gpt-5.6-sol" }],
  trials: 3,
});
```

## Run it

```bash
npx anpord eval ./smoke.eval.ts
```

Anpord compiles the TypeScript locally, then runs each trial in an isolated hosted sandbox.

## Vocabulary

- **Suite:** cases that share a prompt, named by an id derived from its name unless you give one.
- **Case:** the work to do and how to validate it.
- **Variant:** the harness, model, sandbox, profile and simulated user a case runs on.
- **Run:** one case on one variant, with its trials. A case's runs on a variant are its history.
- **Trial:** one attempt within a run.
- **Batch:** the runs started together, such as every case of a suite on every variant.

The eval above is one case, one variant and three trials, so it makes three attempts. Two cases, three variants and three trials would make 18.
