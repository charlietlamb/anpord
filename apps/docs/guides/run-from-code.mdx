---
title: "Run evals from code"
description: "Import an eval and inspect its result"
---

Keep the suite in a typed `*.eval.ts` file and pass `import.meta.url` to `suite`, so the eval knows where it was written:

```ts evals/smoke.eval.ts
export const smoke = suite(import.meta.url, { ... });
```

Then import it and submit it from application code:

```ts
import { Anpord } from "anpord";
import { smoke } from "./evals/smoke.eval";

const anpord = new Anpord();
const run = await anpord.evals.startAndWait(smoke);

if (run.status === "failed") {
  throw new Error(run.failure ?? "Eval run failed");
}

const regressions = run.cells.filter(
  ({ comparison }) => comparison?.verdict === "regressed"
);
const unscored = run.cells.filter(
  ({ distribution }) => (distribution?.scored ?? 0) === 0
);

if (regressions.length || unscored.length) process.exitCode = 1;
await anpord.dispose();
```

Starting bundles the typed validators, preparation, profiles, and MCP, CLI and HTTP mocks into the request. `startAndWait` polls until the run finishes; pass `timeoutMs` or `signal` to control waiting.

A plain request object still works if you have one. `compileEval("./evals/smoke.eval.ts")` compiles by path and needs no argument to `suite`; `compileDefinition` returns the request without sending it. See the [API client](/sdk/client).
