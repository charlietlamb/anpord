---
title: "Run evals from code"
description: "Compile a suite and inspect its result"
---

Keep the suite in a typed `*.eval.ts` file, then compile and submit it from application code:

```ts
import { Anpord } from "anpord";
import { compileEval } from "anpord/eval";

const anpord = new Anpord();
const run = await anpord.evals.startAndWait(
  await compileEval("./evals/smoke.eval.ts")
);

if (run.status === "failed") {
  throw new Error(run.failure ?? "Eval run failed");
}

const regressions = run.cells.filter(
  ({ comparison }) => comparison?.verdict === "regressed"
);
const unscored = run.cells.filter(
  ({ distribution }) => (distribution?.scored ?? 0) === 0
);

if (regressions.length || unscored.length) process.exitCode = 1;
await anpord.dispose();
```

`compileEval` bundles typed validators, preparation, profiles, mock MCP servers, and mock CLIs into the serializable API request. `startAndWait` polls until the run finishes; pass `timeoutMs` or `signal` to control waiting.

Use `anpord.evals.start(request)` only when you already have a compiled request. See the [SDK reference](/tools/sdk) for the lower-level API.
