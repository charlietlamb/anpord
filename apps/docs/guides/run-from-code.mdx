---
title: "Run evals from code"
description: "Import an eval and inspect its result"
---

Export the suite from a typed `*.eval.ts` file, then submit it from application code and act on the result:

```ts
import { Anpord } from "anpord";
import { smoke } from "./evals/smoke.eval";

const anpord = new Anpord();
const batch = await anpord.evals.startAndWait(smoke);

if (batch.status === "failed") {
  throw new Error(batch.failure ?? "Eval batch failed");
}

const failing = batch.runs.filter(({ trials }) =>
  trials.some(({ status }) => status !== "passed")
);

if (failing.length) process.exitCode = 1;
await anpord.dispose();
```

`startAndWait` polls until the batch finishes. Pass `timeoutMs` or `signal` to control waiting.

`compileEval("./evals/smoke.eval.ts")` compiles by path instead, and `compileDefinition` returns the request without sending it. See the [API client](/sdk/client).
