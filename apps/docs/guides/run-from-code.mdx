---
title: "Run evals from code"
description: "Start a batch from your own code and act on the result"
---

Export a suite from a `*.eval.ts` file, start it from your code, and wait for the batch:

```ts
import { Anpord } from "anpord";
import { smoke } from "./evals/smoke.eval";

const anpord = new Anpord();
const { id } = await anpord.evals.start(smoke);
const batch = await anpord.evals.wait({ id });

if (batch.status === "failed") {
  throw new Error(batch.failure ?? "Eval batch failed");
}

const failing = batch.runs.filter(({ trials }) =>
  trials.some(({ status }) => status !== "passed")
);

if (failing.length) process.exitCode = 1;
await anpord.dispose();
```

`start` creates a batch with one run per case per variant and returns its ID. `wait` polls until the batch is no longer `running`. Pass `timeoutMs` (default one hour) or `signal` to stop waiting. Neither cancels the batch.

`startAndWait` does both in one call.

To compile without the client, import from `anpord/eval`: `compileEval("./evals/smoke.eval.ts")` compiles a file by path, and `compileDefinition(smoke)` returns the request without sending it. See the [API client](/sdk/client).
