description: "Prompt management for AI products"
---

Anpord keeps the prompts your product sends to a model outside your codebase, so
changing one does not mean shipping a release.

Content is versioned. Updating a prompt appends a version rather than replacing
one, and a channel decides which version callers receive. Pointing the
`production` channel at a new version is how a change goes live.

## Install

<CodeGroup>

```bash npm
npm install anpord
```

```bash bun
bun add anpord
```

</CodeGroup>

```ts
import { Anpord } from "anpord";

const anpord = new Anpord();

const prompt = await anpord.prompts.get({ id: "support-reply" });
```

With no selector, `get` returns the version the `production` channel points at.
