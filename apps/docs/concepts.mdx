---
title: "How evals work"
description: "Cases, variants, trials and runs"
---

An eval defines what an agent should do and how to check its work.

Each run tests your cases using the agents and models you choose. Repeat each test with multiple trials to see how consistently it passes.

- **Case:** the work to do and how to validate it.
- **Variant:** the agent, model and sandbox configuration.
- **Trial:** one attempt at a case with a variant.
- **Run:** all the attempts started together.

Two cases, three variants and three trials produce 18 attempts.

See [results](/evals/results) to inspect a run or [baselines](/evals/baselines) to compare results over time.
