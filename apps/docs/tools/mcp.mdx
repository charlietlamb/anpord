Connect to the hosted server:

<CodeGroup>

```json Claude Desktop
{
  "mcpServers": {
    "anpord": { "url": "https://mcp.anpord.com/mcp" }
  }
}
```

```bash Claude Code
claude mcp add --transport http anpord https://mcp.anpord.com/mcp
```

</CodeGroup>

The server uses OAuth 2.1. Your browser opens for sign-in and approval, so the MCP configuration does not contain an API key. Eval reads need `evals:read`, and starting runs needs `evals:write`.

## Eval tools

| Tool | Purpose |
| --- | --- |
| `list_eval_batches` | List a page of batches, newest first |
| `list_eval_models` | List models available to a harness |
| `start_eval_batch` | Run every case of a suite on every variant |
| `get_eval_batch` | Read a batch's runs and trials |
| `list_case_runs` | Read a case's runs, optionally on one variant |
| `run_eval_case` | Run a case again on one variant, or on all of them |

`start_eval_batch` and `run_eval_case` return a batch id immediately. Poll `get_eval_batch` until its status is no longer `running`.

`list_eval_batches` returns `batches` and `next`. Pass `next` as `cursor` for the following page.
