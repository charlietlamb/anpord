Connect to the hosted server:

<CodeGroup>

```json Claude Desktop
{
  "mcpServers": {
    "anpord": { "url": "https://mcp.anpord.com/mcp" }
  }
}
```

```bash Claude Code
claude mcp add --transport http anpord https://mcp.anpord.com/mcp
```

</CodeGroup>

The server uses OAuth 2.1. Your browser opens to sign in and approve access, so the MCP configuration holds no API key. Reading evals needs `evals:read`. Starting a batch needs `evals:write`.

## Eval tools

| Tool | Purpose |
| --- | --- |
| `start_eval_batch` | Start a batch: every case of a suite on every variant |
| `run_eval_case` | Start a batch that runs one case's newest version again, on one variant or on all of them |
| `get_eval_batch` | Read a batch with its runs and their trials |
| `list_eval_batches` | List batches, newest first |
| `list_case_runs` | List a case's runs, newest first, optionally on one variant |
| `list_eval_models` | List the models a harness can use |

`start_eval_batch` and `run_eval_case` return the batch ID and one run ID per case per variant right away. Poll `get_eval_batch` until its `status` is no longer `running`.

`list_eval_batches` returns `batches` and `next`. Pass `next` as `cursor` to read the following page.
