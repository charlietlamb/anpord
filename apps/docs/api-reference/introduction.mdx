The public API is available at `https://api.anpord.com/v1`.

Every operation is a `POST` with a JSON body, including reads:

```text
POST /v1/evals.start
POST /v1/evals.get
POST /v1/evals.list
```

There are no path or query parameters.

## Authentication

Pass an API key as a bearer token:

```bash
curl https://api.anpord.com/v1/evals.list \
  -H "authorization: Bearer $ANPORD_API_KEY" \
  -H "content-type: application/json" \
  -d '{"limit":20}'
```

Keys belong to one organization. OAuth access tokens are also accepted. Eval reads use `evals:read`, and starting runs uses `evals:write`.

## Asynchronous evals

`evals.start` runs every case of a suite on every variant. It returns the batch id, and a run id per case and variant, while work continues on the server:

```bash
curl https://api.anpord.com/v1/evals.start \
  -H "authorization: Bearer $ANPORD_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "suite": { "id": "smoke", "name": "Smoke", "prompt": "{{task}}" },
    "cases": [{
      "id": "writes-hello",
      "name": "writes the requested file",
      "prepare": null,
      "source": { "kind": "empty" },
      "variables": { "task": "Create hello.txt containing exactly hello" },
      "verify": "test \"$(cat hello.txt)\" = hello"
    }],
    "variants": [{
      "harness": "codex",
      "model": "gpt-5.6-sol",
      "sandbox": "daytona"
    }],
    "trials": 3
  }'
```

Poll `evals.get` with the returned id until `status` is `finished` or `failed`.

One request may contain at most 100 total trials. Starting a batch is not idempotent. If its response is lost, list recent batches before retrying.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid request body |
| `401` | Missing or invalid bearer token |
| `403` | Missing permission |
| `404` | Resource not found |
| `409` | Request conflicts with current state |

Declared errors return JSON with a `message`. The [TypeScript client](/sdk/client) decodes responses and throws `AnpordError` for failures.
