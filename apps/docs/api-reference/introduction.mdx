The public API is available at `https://api.anpord.com/v1`.

Every operation is a `POST` with a JSON body, including reads:

```text
POST /v1/evals.start
POST /v1/evals.get
POST /v1/prompts.get
POST /v1/prompts.promote
```

There are no path or query parameters.

## Authentication

Pass an API key as a bearer token:

```bash
curl https://api.anpord.com/v1/evals.list \
  -H "authorization: Bearer $ANPORD_API_KEY" \
  -H "content-type: application/json" \
  -d '{"limit":20}'
```

Keys belong to one organization. OAuth access tokens are also accepted. Eval reads use `evals:read`; starts and reruns use `evals:write`. Prompt reads use `prompts:read`, prompt writes use `prompts:write`, and promotion uses `channels:write`.

## Asynchronous evals

`evals.start` returns an id while work continues on the server:

```bash
curl https://api.anpord.com/v1/evals.start \
  -H "authorization: Bearer $ANPORD_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "cases": [{
      "name": "writes the requested file",
      "task": "Create hello.txt containing exactly hello",
      "verify": "test \"$(cat hello.txt)\" = hello"
    }],
    "prompt": "{{task}}",
    "tasks": [{
      "harness": "codex",
      "model": "gpt-5.6-sol",
      "provider": "daytona"
    }],
    "trials": 3
  }'
```

Poll `evals.get` with the returned id until `status` is `finished` or `failed`.

One request may contain at most 100 total trials. Starting a run is not idempotent. If its response is lost, list recent runs before retrying.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid request body |
| `401` | Missing or invalid bearer token |
| `403` | Missing permission |
| `404` | Resource not found |
| `409` | Request conflicts with current state |

Declared errors return JSON with a `message`. The [TypeScript SDK](/tools/sdk) decodes responses and throws `AnpordError` for failures.
