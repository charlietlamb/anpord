Anpord runs coding tasks across harnesses, models, and sandboxes, then keeps the verifier result and agent trajectory for each attempt.

```ts
const { id } = await anpord.evals.start({
  cases,
  prompt: "Work in the current repository. {{task}}",
  tasks: [{ harness: "codex", model, provider: "daytona" }],
  trials: 3,
});
```

Repeat the same cell to compare it with its first scored result. Anpord marks the change as `improved`, `unchanged`, `regressed`, or `incomparable`.

Anpord also stores prompts outside your application. Every edit creates a version, and channels decide which version callers receive.

```ts
const prompt = await anpord.prompts.get({ id: "coding-agent" });
```
