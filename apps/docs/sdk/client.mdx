## Create a client

```ts
import { Anpord } from "anpord";

const anpord = new Anpord();
```

The client reads `ANPORD_API_KEY`. Pass `apiKey` or `baseUrl` when needed:

```ts
const anpord = new Anpord({
  apiKey: process.env.MY_ANPORD_KEY,
  baseUrl: "http://127.0.0.1:3003",
});
```

## Evals

| Method | Returns |
| --- | --- |
| `evals.start(request)` | A batch id, and a run id per case and variant, while trials continue on the server |
| `evals.startAndWait(request)` | The finished batch |
| `evals.get({ id })` | One batch with its runs and trials |
| `evals.wait({ id })` | An already-started batch once it finishes |
| `evals.list({ cursor?, limit? })` | A page of batches and its next cursor |
| `evals.models({ harness })` | Models available to a harness |
| `evals.caseRuns({ caseId, variant?, page? })` | A page of a case's runs, newest first |
| `evals.runCase({ caseId, variant?, trials })` | A new batch running the case on one variant, or on every variant |

```ts
const { id, runs } = await anpord.evals.start({
  cases,
  suite: { id: "smoke", name: "Smoke", prompt: "{{task}}" },
  variants: [{ harness: "codex", model }],
  trials: 3,
});
```

Validators, preparation, profiles and mock dependencies live in an eval file. Import it and hand it over:

```ts evals/smoke.eval.ts
export const smoke = suite({ ... });
```

```ts
import { smoke } from "./evals/smoke.eval";

const batch = await anpord.evals.startAndWait(smoke);
```

A suite records the file it was written in, which is how its validators and mock servers reach the sandbox with everything they close over. `start` and `startAndWait` compile it for you.

## Errors and cleanup

```ts
import { AnpordError } from "anpord";

try {
  await anpord.evals.get({ id: "missing" });
} catch (error) {
  if (error instanceof AnpordError) {
    console.error(error.status, error.message);
  }
}

await anpord.dispose();
```

Invalid request fields fail before a network call. API failures include an HTTP status when available.

SDK date fields are Effect `DateTime.Utc` values. Read `epochMillis` when you need a number.
