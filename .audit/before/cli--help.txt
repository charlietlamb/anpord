Anpord

Anpord 0.1.26

USAGE

$ anpord

DESCRIPTION

Run evals from the terminal

OPTIONS

--completions sh | bash | fish | zsh

  One of the following: sh, bash, fish, zsh

  Generate a completion script for a specific shell.

  This setting is optional.

--log-level all | trace | debug | info | warning | error | fatal | none

  One of the following: all, trace, debug, info, warning, error, fatal, none

  Sets the minimum log level for a command.

  This setting is optional.

(-h, --help)

  A true or false value.

  Show the help documentation for a command.

  This setting is optional.

--wizard

  A true or false value.

  Start wizard mode for a command.

  This setting is optional.

--version

  A true or false value.

  Show the version of the application.

  This setting is optional.

COMMANDS

  - eval [--json] [--case text] [--fail-on failures | strict | never] [--local] [--no-wait] [--output text] [--timeout integer] [--ui] --variant text... [<file>]                                                        Run suite files, or a stored case, as batches and gate on the results

  - eval [--json] [--case text] [--fail-on failures | strict | never] [--local] [--no-wait] [--output text] [--timeout integer] [--ui] --variant text... [<file>] import --format evals-json | yaml [--out file] <path>  Turn a case file a team already wrote into a suite

  - connectors                                                                                                                                                                                                           Connect the credentials an eval run needs

  - connectors add [--auth text] [--default] [--name text] <integration>                                                                                                                                                 Connect an integration. The secret is prompted for, or read from stdin

  - connectors integrations [--json]                                                                                                                                                                                     List the integrations that can be connected

  - connectors list [--json]                                                                                                                                                                                             List the connectors this organization has

  - connectors remove <id>                                                                                                                                                                                               Remove a connector

  - whoami [--json]                                                                                                                                                                                                      Show the organization and key ANPORD_API_KEY acts for

exit 0
