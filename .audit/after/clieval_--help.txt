Anpord

Anpord 0.1.26

USAGE

$ eval [--json] [--case text] [--fail-on failures | strict | never] [--local] [--no-wait] [--output text] [--timeout integer] [--ui] --variant text... [<file>]

DESCRIPTION

Run suite files, or a stored case, as batches and gate on the results

ARGUMENTS

<file>

  A user-defined piece of text.

  A TypeScript eval file; discovers *.eval.ts when omitted

  This setting is optional.

OPTIONS

--json

  A true or false value.

  Print each finished batch as JSON

  This setting is optional.

--case text

  A user-defined piece of text.

  Run one case. With a file, picks that case from it; without one, runs the stored case again

  This setting is optional.

--fail-on failures | strict | never

  One of the following: failures, strict, never

  failures fails on any run whose trials did not all pass, strict also requires every expected run and trial, never only fails a batch that did not finish

  This setting is optional.

--local

  A true or false value.

  Run every case on every variant on this machine instead of a cloud sandbox

  This setting is optional.

--no-wait

  A true or false value.

  Start batches without waiting

  This setting is optional.

--output text

  A user-defined piece of text.

  Write a JSON report to this file

  This setting is optional.

--timeout integer

  An integer.

  Maximum seconds to wait per batch, 1200 unless set

  This setting is optional.

--ui

  A true or false value.

  Open the dashboard for this batch in a browser

  This setting is optional.

--variant text...

  A user-defined piece of text.

  Run one variant: harness/model, harness/model@profile or a profile name for a file, or a variant id for a stored case. Repeat for more

  This option may be repeated zero or more times.

--completions sh | bash | fish | zsh

  One of the following: sh, bash, fish, zsh

  Generate a completion script for a specific shell.

  This setting is optional.

--log-level all | trace | debug | info | warning | error | fatal | none

  One of the following: all, trace, debug, info, warning, error, fatal, none

  Sets the minimum log level for a command.

  This setting is optional.

(-h, --help)

  A true or false value.

  Show the help documentation for a command.

  This setting is optional.

--wizard

  A true or false value.

  Start wizard mode for a command.

  This setting is optional.

--version

  A true or false value.

  Show the version of the application.

  This setting is optional.

COMMANDS

  - import --format evals-json | yaml [--out file] <path>  Turn a case file a team already wrote into a suite

exit 0
